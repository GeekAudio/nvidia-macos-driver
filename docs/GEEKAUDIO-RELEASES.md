# GeekAudio 累计发布

每个正式版和 RC 都从指定的 NullMoth 官方版本构建成一个完整安装包。上一版中仍由 GeekAudio 维护的功能和修复随新版本一起交付，每次新增的功能合入这份完整集合。已由官方实现接手的功能沿用官方基线，并记录接手的版本或提交。需要保留开关的实验功能继续按原开关提供。

历史发行保留当时的附件和验证范围。每版的发行说明先写当前版本的功能集合，再写本次变化和实测范围。包里有代码、注册成功、实机跑通是三个不同的验证结果。

## 3.0 累计完整包

适配分支 `codex/upstream-3.0-integration` 合入上游 `87e524ab`，共纳入原 2.9 基线后的 82 个提交。官方发行基线为 `v3.0`。完整包已在本机安装并重启验证。四个内核组件均加载为 3.0，系统服务映射的 Metal 插件与本版一致。

- 上游的 `nvk-stream-uncached.patch` 修复命令与上传流被 GPU 缓存后读到旧命令的问题。构建时使用 3.0 的 NVK 补丁链；2.9 的 NVK 二进制不能代替这项更新。既有 Dock、日历、窗口控件同步提交策略先保留，是否移除须在同机使用新版 NVK 对照验证。
- 保留 RTX 30 的默认 H.264／HEVC 快速硬解、PCI 设备证据、Ada 编解码选择、Firefox 注入工具、DP 亮度写入与探测重试、QQ 模板导出识别、图标及 Core Image 修复，以及更新 App 1.3.0 的中英文界面。
- 五处冲突分别涉及 framebuffer 清理、WindowServer 表面标记、纹理上传、编解码 RM 连接与 HEVC 注册。解决后同时保留上游的背光全局引用清理、每个表面平面每次提交只标记一次、多重采样上传拒绝与旧系统 API 条件，以及本分支的多平面别名、异步上传生命周期、设备上报和 Ampere 解码选择。
- 252 项主机测试通过，9 项需要专用构建输入或硬件环境。新增多平面别名的去重验证，补齐测试夹具与有效历史对照。Metal 插件、NVEncVT 和 NVRMFB 均以 x86_64、最低 macOS 15 构建通过，三个构建均零警告。NVRMFB 导入的 IOKit 家族声明检查通过。
- 3.0 整包在 RTX 3080、macOS 26.7.3（25G342）重启后完成 1080p H.264、HEVC 各 4,500 帧硬编与硬解，零解码错误、零抽样像素错误，两个解码会话均上报实际 PCI 设备。Metal 双向复制 16 轮通过，两块显示器亮度接口写入、回读、恢复均成功。窗口服务错误检查未记录设备丢失或上传失败。
- RTX 4060 尚待同机复测。菜单、图标和 QQ 搜索框在 3.0 上的完整交互回归仍需继续观察，之前的实机结果见下文 2.9 清单。

## 每次发布前

1. 对照上一版的完整功能清单和新官方基线。逐项记录继续随包、已由官方接手、按决定移除或仍待补齐。未获批准的功能缺口先解决，再发布新的驱动构建。
2. 在同一个完整安装包中核对官方基线、所有应保留的 GeekAudio 功能、双系统所需驱动、安装和回滚脚本以及许可证。重解压后检查文件清单、SHA-256、关键签名和目标机的 AuxKC／启动，记录每项实测的系统、显卡与应用。
3. 发布 `01-geekaudio-nullmoth-<版本>-full.tar.gz` 和同页的 `02-GeekAudio-ReleaseChecker-macOS.zip`，同时提供校验值、构建信息和签名安装清单。整包须包含 Firefox 注入库、启动脚本和 mickys/nvenc 的许可证。完整包是唯一驱动下载，手动安装与 App 使用同一份归档。[清单签名流程](../tools/ReleaseChecker/README.md)
4. 发布后从公开地址重新下载整包与校验清单，并用更新 App 的校验流程核对同一个归档。RC 标题统一使用 `GeekAudio NullMoth <版本> RC<编号>`，正式版使用 `GeekAudio NullMoth <版本>`。
